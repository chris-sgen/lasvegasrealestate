What the build fixes

  • Hidden spam links taken out. 364 of the 381 live pages read carry a block of 109 links to 82 other sites (by their link words: film and TV streaming, betting, live sports and adult sites), pushed far off the screen so that visitors never see it, every link marked rel="dofollow". Hidden links like these go against Google's spam policies and can cost a site its rankings. The handoff build has none (0 pages). Because visitors never see the block, it is easy to miss: it should also be taken off the live site.
  • One h1 on every page. Of the 381 live pages read, 138 have no h1 heading and 31 have more than one. Of the 352 that the build rebuilds, 352 now have exactly one.
  • A canonical address on every page. 38 live pages read have none (35 of them rebuilt). Every canonical in the build names the page's own address on www.lasvegasrealestate.com (352 of 352), never this preview.
  • Alt text. On the 352 rebuilt pages the live site has 4,722 picture tags with no alt attribute; the build has 0. An empty alt (2,691 in the build) tells screen readers to pass over a picture.
  • No server warnings in the text. 51 of the 381 live pages read print a server warning (a line of the site's code failing) in the middle of their text, where search engines read it as content. The build has 0.
  • A cleaner sitemap. The live sitemap lists 347 different addresses; 28 of them are pages with nothing of their own to rebuild (empty and test pages, drafts, copies, pages that print only an error), which the build forwards to the page that answers them. The build's sitemap lists the 305 pages that are meant to be found.

What the build keeps

  • Addresses. Every page of the build that was read on the live site keeps its address there. The 29 live addresses read that are not rebuilt (empty and test pages, drafts, copies) are forwarded with a 301 to the page that answers them. 5 more addresses in the live sitemap could not be read for the redesign, and are neither built nor forwarded: /checkout/, /idx-details/, /idx/featured-open-houses/, /things-to-do/, /utilities/. 1 address with a query string (/?sr-listings=knds-listing-search) answered with another page and is not counted as a page here.
  • Titles. 352 of the 352 page titles are the live site's own, word for word.
  • Descriptions. 293 meta descriptions are the live site's own, word for word. The 59 rebuilt pages that have none on the live site still have none (33 of them are noindex): writing them is the business's call (see below).
  • Noindex where the live site set it. 38 of the live pages read ask not to be indexed (35 of them lists of categories, tags or partner categories). The build keeps noindex on the 35 of them it rebuilds; 3 are forwarded instead. It gives the same noindex to its other 147 category and tag lists, which were not read, because every such list read on the live site has it. No page that is indexable on the live site is noindex in the build.
